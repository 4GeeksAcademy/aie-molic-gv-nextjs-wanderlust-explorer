# Identidad visual — Wanderlust Explorer

Este documento establece la referencia visual común para las futuras especificaciones SDD y para todas las páginas de Wanderlust Explorer. La interfaz de usuario estará en español.

## Estética

La experiencia tendrá un diseño editorial de viajes: moderno, natural y elegante, con un carácter ligeramente premium. Debe transmitir aventura, autenticidad y descubrimiento, apoyándose en fotografías inmersivas y una interfaz limpia e intuitiva.

## Paleta de colores

| Uso | Color | Código |
|---|---|---|
| Color primario | Verde bosque profundo | `#184E45` |
| Color de acento | Terracota cálido | `#E58B5B` |
| Fondo principal | Crema cálido | `#F8F6F0` |
| Tarjetas y superficies | Blanco puro | `#FFFFFF` |
| Texto principal | Carbón oscuro | `#202B28` |
| Texto secundario | Verde salvia | `#74837C` |

El contraste entre texto y superficies debe ser adecuado y verificarse para mantener una lectura accesible.

## Tipografía e iconografía

- **Títulos:** Playfair Display.
- **Texto general:** Inter.
- **Iconografía:** Lucide Icons.

## Principios de diseño

- Diseñar con enfoque mobile-first y adaptar la interfaz a distintos tamaños de pantalla.
- Usar espaciado generoso para favorecer la lectura y dar protagonismo al contenido visual.
- Preferir tarjetas con bordes redondeados y sombras sutiles.
- Mantener una jerarquía visual clara y una navegación intuitiva.
- Considerar accesibilidad y contraste adecuado en todos los elementos.
- Mantener coherencia visual entre todas las páginas.
- Favorecer componentes reutilizables en futuras decisiones de diseño e implementación.
